# Task Manager App (Expo + Bare React Native + NativeWind)

Minimal Task Manager App:

- Login: admin / 1234
- Tasks list
- Add task, toggle complete, statistics, (optional) delete
- News api

## Tech

- Expo (SDK 52+ recommended)
- expo-router
- nativewind (className)
- reactnativereusables (UI components)
- Mmkv, Expo Secure Store, AsyncStorage (persistence)

## Quick Start from GitHub

Clone the repository:

```bash
git clone <REPO_URL> my-task-app
cd my-task-app

npm install

npx expo run:android
```
